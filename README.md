## 📌 Project Overview

The **Olympic SQL Analysis Project** is a comprehensive SQL data analysis project built using **PostgreSQL** and an Olympic athletes dataset containing historical records of athlete participation, events, teams, sports, host cities, and medals.

The primary purpose of this project is to demonstrate and strengthen practical SQL skills by analyzing real-world-style data through a structured set of analytical questions.

The project contains **20 SQL questions**, organized into three different difficulty levels:

- 🟢 **Easy Level** — Fundamental SQL concepts and data retrieval
- 🟡 **Intermediate Level** — Aggregations, grouping, and analytical calculations
- 🔴 **Advanced Level** — Complex analysis using CTEs, conditional aggregation, and Window Functions

Throughout the project, the dataset is explored to answer meaningful questions related to Olympic participation and performance. The analysis includes athlete participation across different Olympic Games, team and country performance, medal distribution, unique athlete counts, host city analysis, and comparisons between Summer and Winter Olympic participation.

The project gradually progresses from simple data retrieval queries to more advanced analytical problems. This approach helps demonstrate how SQL can be used not only to retrieve data but also to transform raw data into meaningful insights.

### Key Areas of Analysis

The project focuses on several important areas of Olympic data analysis:

- 👥 **Athlete Analysis**  
  Identifying unique athletes, analyzing participation, age, gender, and Olympic Games involvement.

- 🌍 **Team and Country Analysis**  
  Examining the number of athletes representing each team and comparing Olympic participation across countries.

- 🏅 **Medal Analysis**  
  Calculating Gold, Silver, and Bronze medals won by different teams and identifying top-performing countries.

- 🏟️ **Olympic Games Analysis**  
  Analyzing Olympic years, host cities, sports, events, and athlete participation across different Games.

- ❄️☀️ **Season Analysis**  
  Identifying athletes who participated in both the Summer and Winter Olympic Games.

- 📊 **Performance Analysis**  
  Calculating medal-winning rates and creating an overall Olympic performance report for each team.

- 🏆 **Ranking and Advanced Analysis**  
  Using Window Functions such as `DENSE_RANK()` to identify top-performing teams and sports.
