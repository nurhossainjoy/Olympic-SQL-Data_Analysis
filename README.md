## 📌 Project Overview

This project demonstrates practical **SQL data analysis skills** using a comprehensive Olympic athletes dataset.

The analysis consists of **20 SQL questions**, carefully organized into three difficulty levels:

- 🟢 **Easy Level** — 6 Questions
- 🟡 **Intermediate Level** — 7 Questions
- 🔴 **Advanced Level** — 7 Questions

The project covers fundamental to advanced SQL concepts, including data filtering, aggregation, conditional aggregation, Common Table Expressions (CTEs), and Window Functions.
